# 📦 Verified Logistics Dashboard

An interactive Streamlit dashboard designed to monitor inventory, warehouse operations, and supply chain performance.

## 📊 Dashboard Features

- Inventory overview
- Stock levels by category
- Stockout analysis
- Fulfillment rate monitoring
- Warehouse zone performance
- Picking time analysis
- Demand analysis
- Inventory turnover analysis
- KPI performance monitoring
- Interactive category and warehouse filters

## 🛠️ Tools & Technologies

- Python
- Streamlit
- Pandas
- Plotly
- GitHub

## 📈 Key Performance Indicators

The dashboard tracks:

- Total Items
- Total Stock
- Fulfillment Rate
- Stockouts
- Inventory Turnover Ratio
- KPI Score
